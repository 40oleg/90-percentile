# 90 Percentile

Пиксельный трекер физических испытаний. Выполни все челленджи, чтобы стать сильнее и спортивнее 90% людей на планете.

PWA на Angular — устанавливается на телефон прямо из браузера. Прогресс хранится локально в устройстве.

## Разделы

- **Челленджи** — список испытаний с отметками о выполнении и видео-пруфами.
- **Ккал** — журнал калорий со средним за день.
- **Тест** — тесты по темам: 15 вопросов за попытку, разбор ошибок и график процента
  правильных ответов за последние 90 попыток.

### Как добавить новую тему теста

1. Создай `src/app/data/quiz/<тема>.questions.ts`, экспортирующий массив `QuizQuestion[]`
   (четыре варианта ответа, `correctIndex`, пояснение).
2. Добавь тему в `QUIZ_TOPICS` в `src/app/data/quiz-topics.data.ts`.

Всё остальное — экраны, хранилище попыток и статистика — подхватывается автоматически.
Попытки хранятся по `id` темы, поэтому менять его у существующей темы нельзя: история
привяжется к новому идентификатору. Длину теста можно переопределить полем
`questionsPerRun`.

## Разработка

```bash
npm install
npm start        # http://localhost:4200
npm run build     # production-сборка в dist/90-percentile
```

## Деплой

При каждом push в `main` GitHub Actions собирает приложение и публикует его на GitHub Pages
(`.github/workflows/deploy.yml`). В настройках репозитория: **Settings → Pages → Build and
deployment → Source: GitHub Actions**.
